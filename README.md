# NomadTable

Social discovery app for solo travelers: a live map of nearby travelers and local events, with event invites, saved events, chat and notifications.

- `app/` — React Native (Expo) frontend. `npm install && npm run web`
- `server/` — Express API with in-memory data (no database yet). `npm install && npm start` (port 3001)

The app currently runs on its own mock data and is not yet wired to the API.
